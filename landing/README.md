# FreeTPV Landing

Landing page oficial de FreeTPV, creada con Next.js y Tailwind CSS.

## Desarrollo local

```bash
npm install
npm run dev
```

Después abre `http://localhost:3000` en el navegador.

## Scripts

```bash
npm run dev      # Servidor de desarrollo
npm run build    # Compilación de producción
npm run start    # Servidor de producción
npm run lint     # Revisión con ESLint
```

## Estructura principal

- `app/page.tsx`: composición de la página.
- `app/layout.tsx`: metadatos, fuentes y layout raíz.
- `app/globals.css`: variables visuales y configuración base de Tailwind.
- `components/`: secciones de la landing.
- `public/logo.png`: logo usado en cabecera, hero y footer.
